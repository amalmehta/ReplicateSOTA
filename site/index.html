Qwen3.5, rebuilt from scratch

Qwen3.5-0.8B, released in February 2026, uses ordinary attention in only 6 of its 24 layers. The other 18 keep a small memory that they correct rather than add to. This page rebuilds the whole model in plain PyTorch, checks it against the official one at every position, and tests whether that correcting memory really recalls better.

The shape of the model

Each of the 24 blocks does two things: it mixes information across tokens, then it transforms each token on its own (a small MLP). The interesting part is the mixing. Three blocks in every four use Gated DeltaNet, a linear-attention layer with a fixed-size memory. Every fourth block uses ordinary softmax attention, which can look back at any earlier token exactly.

Gated DeltaNet (18)Full attention (6)

Why mix the two? Attention's memory (the KV cache, the stored keys and values of every past token) grows with every token. DeltaNet's memory stays the same size however long the text is. The table below works this out from the model's own config.

Gated DeltaNet in four lines

Think of each DeltaNet head as a notebook. Each page is a key (what something is about), and on it is a value (what to remember about it). Plain linear attention writes every new note on top of the old ones, so after a while the pages smear together. The delta rule first reads what the notebook already says for this key, then writes only the difference. The gate lets old ink fade, so stale notes stop getting in the way.

$$\alpha_t = \exp\!\big(-e^{A}\,\operatorname{softplus}(a_t + b)\big),\qquad \beta_t = \sigma(\tilde b_t)$$
\(\alpha_t\)
forget gate, between 0 and 1 (1 = keep everything)
\(\beta_t\)
write strength, between 0 and 1
\(a_t, \tilde b_t\)
one number per head, computed from the current token
\(A, b\)
learned per-head constants
\(\sigma\)
the sigmoid function

Step 1. The token decides how much to forget and how hard to write.

$$\hat v_t = (\alpha_t S_{t-1})^{\top} k_t$$
\(S_{t-1}\)
the memory, a \(128 \times 128\) matrix per head (key size × value size)
\(k_t\)
this token's key, scaled to length 1
\(\hat v_t\)
what the faded memory currently returns for this key

Step 2. Look the key up in the faded memory.

$$S_t = \alpha_t S_{t-1} + \beta_t\, k_t\,(v_t - \hat v_t)^{\top}$$
\(v_t\)
the value this token wants stored
\(v_t - \hat v_t\)
the error: what the memory gets wrong

Step 3. Write only the correction. Plain linear attention would write all of \(v_t\) instead, with \(\alpha_t = \beta_t = 1\).

$$o_t = S_t^{\top} q_t$$
\(q_t\)
this token's query, scaled to length 1 and then by \(1/\sqrt{128}\)
\(o_t\)
the head's output for this token

Step 4. Read the updated memory with the query.

Step 3 is one step of gradient descent. The memory is trained, online, to map keys to values, with \(\beta_t\) as its learning rate. That's why it can overwrite a stale entry, and why plain linear attention can only pile entries on top of each other.

Try it: store pairs, then read them back

The memory here is small: 8-dimensional keys, so at most 8 keys can point in fully independent directions. Store more pairs than that and the keys must overlap. Watch how each rule copes.

Bars show the average recall error: the distance between the value read back and the value stored, where 0 is perfect. Both rules use \(\alpha=1\) (no forgetting); the delta rule uses \(\beta=1\). The keys are random but use a fixed seed. Things to notice: past 8 pairs, linear attention's error keeps growing while the delta rule's levels off. Raise "times seen" and the delta rule keeps improving, because each pass is another gradient step (with 6 pairs, 8 passes cut its error by more than half). Linear attention stays where it was, because seeing a pair again only adds the same note again, so the overlap between notes never gets fixed.

The attention layers have a gate too

$$o = \operatorname{softmax}\!\Big(\tfrac{QK^{\top}}{\sqrt{256}} + M\Big)V \;\odot\; \sigma(G)$$
\(Q, K, V\)
queries (8 heads), keys and values (2 heads, shared by 4 query heads each), size 256
\(M\)
causal mask: \(-\infty\) above the diagonal, so no token sees the future
\(G\)
a gate projected from the same input as \(Q\)
\(\odot\)
element-wise product

This is ordinary attention, then each output channel is multiplied by a learned gate between 0 and 1. That lets a head say "nothing useful here" instead of being forced to output a weighted average.

Two smaller details matter for an exact match. First, rotary position encoding (RoPE) turns only the first 64 of each head's 256 channels. Second, every RMSNorm multiplies by \(1 + w\) rather than \(w\). Get either one wrong and the outputs drift within a few layers.

Is the rebuild exact?

"Replicated" is defined up front as a test that can't be fudged. The official transformers model and ours run in fp32 on the same 8 prompts. These range from a single token to 4,534 tokens, and include code, Chinese, emoji and repeated text. At every position:

  1. the largest difference in any next-token score must be ≤ 10−4 (first set at 10−3, then tightened once the first run measured 5.3×10−5);
  2. the top predicted token must be the same;
  3. a 32-token greedy continuation must match token for token.

Does the correcting memory recall better?

The matching test proves the maths was copied correctly. It doesn't prove the delta rule does what it promises. So we train three tiny two-layer models from scratch on associative recall. Each one sees key–value pairs at the start of a sequence, then the keys again later, and must output each key's value.

Hypothesis, stated before running: Gated DeltaNet beats plain linear attention at every sequence length. Softmax attention is the upper baseline.

Why "inconclusive": softmax attention can look back at every earlier token, so it can solve this task at any length here. When it fails on some seeds, the runs are all-or-nothing: a model either "clicks" within the 1,500 steps or stays near chance. Averages over such runs measure how fast training takes off, not how much the memory holds. ± is the sample standard deviation over seeds. This rule was added after seeing the results. The win-by-more-than-the-spread rule was fixed before.

Exact setup and how it differs from the papers

What this does not show

  • Only the text path. The vision encoder and the extra multi-token-prediction head are not rebuilt.
  • Matching inference doesn't show how Qwen trained the model. Data, compute and recipe are not public.
  • The recall experiment is tiny and runs on CPU. It shows a direction, not the papers' numbers. The Gated DeltaNet paper itself tests recall on S-NIAH (a needle-in-a-haystack task), not this one.
The reusable idea. To check that you've understood a model, rebuild it and compare against the original at every position, with a tolerance you fix before running. Then test the one claim that makes the model new with the smallest experiment that could prove it wrong.
